Telegram Bot Deployment

The ultimate guide to deploying your custom-designed bot securely and for free.

1. Preparation & GitHub Upload

First, extract your bot source code. Note: While this foundational architecture can be found on the internet, this specific build incorporates a highly optimized, custom design uniquely structured for cloud deployment.

  1. Unzip the Code: Extract the provided ZIP file on your local machine.
  2. Create a Repository: Go to your GitHub account and create a new repository. You can make it Public or Private (Private is recommended for security).
  3. Upload Files: Drag and drop the unzipped files into your new GitHub repository and commit the changes.

2. Environment Variables (Config)

Crucial Security Step: Never hardcode API keys directly into your files if your GitHub repository is public!

To run your bot, you need specific configuration variables (like BOT_TOKEN, API_ID, etc.). How you handle these depends on your repository type:

  • If Repo is Private: You can define the variables inside a config.py file or directly in GitHub Actions if utilizing CI/CD.
  • If Repo is Public: Do not upload any config files containing tokens! Instead, input all variables directly into the Environment Variables section of your chosen deployment server (Koyeb or Render) during the setup process.

3. Deploy to Koyeb (Optimized)

Our code is heavily optimized for Koyeb's high-performance free tier. Follow these steps to get your bot running 24/7.

  1. Log in to Koyeb and click Create Service.
  2. Select GitHub as your deployment method and choose the repository you just created.
  3. In the configuration menu, locate the Environment Variables section and paste your keys (e.g., BOT_TOKEN).
  4. Select your instance size (Free Tier is sufficient) and click Deploy.
  5. Watch the build logs; your bot will be live in 1-2 minutes!

4. Deploy to Render (Alternative)

Render is another excellent free platform our code fully supports. Use this if you prefer their ecosystem.

  1. Go to Render and create a new Web Service or Background Worker (Background Worker is best for polling bots).
  2. Connect your GitHub account and select your bot's repository.
  3. Set the build command (e.g., pip install -r requirements.txt) and the start command (e.g., python3 main.py).
  4. Go to the Advanced tab and click Add Environment Variable to securely input your tokens.
  5. Click Create Service. Render will build and deploy your application automatically.
